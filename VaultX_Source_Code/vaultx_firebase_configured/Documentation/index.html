Installation

  1. Install Node.js 20.9+.
  2. Open Main-Application in a terminal.
  3. Run npm install, then npm run dev.
  4. Visit http://localhost:3000.

Without Firebase settings, the app runs a public read-only demo featuring synthetic values.

Firebase setup

  1. Create a Firebase project.
  2. In Authentication, enable Email/Password.
  3. In Firestore, create a database.
  4. Deploy the supplied firestore.rules. Do not leave Firestore open to everyone.
  5. Copy .env.example to .env.local and set API key, auth domain, project ID, and app ID from your Firebase Web App.
  6. Restart the development server.

Authenticated users can only create, list, and delete their own portfolio names/descriptions. Test access-control rules before any public deployment.

Deploying to Vercel

  1. Push Main-Application into a Git repository (or import the monorepo with the root directory set to Main-Application).
  2. Import project into Vercel and choose Next.js.
  3. For a credential-free public demo, leave Firebase env vars unset or set NEXT_PUBLIC_VAULTX_DEMO=1.
  4. For user accounts, add the four NEXT_PUBLIC_FIREBASE_* environment values and redeploy.
  5. Add your deployment domain to Firebase Authentication → Authorized domains.
  6. Check homepage, dashboard, sign-in, and portfolio create/delete.

Customization

Colors and layout are defined in src/app/globals.css. Navigation is defined in src/components/shell.tsx. Sample data resides in src/lib/demo.ts. Brand text appears in the shared shell and landing page.

Known limitations

This is an implementation preview, NOT the completed commercial product. The admin page is informational; market values are synthetic; exports are sample CSV; AI, automation, financial transaction processing, enterprise tenancy, billing, live data, and most feature claims from the long-term product spec have not been implemented. npm installation/build/browser tests could not be run in the packaging environment. Screenshots enclosed are styled design previews, not certified captures of a deployed production app.

Support / Troubleshooting

Missing Firebase environment: public demo is intended. Authentication failure: check Email/Password provider and authorized domains. Firestore permission denied: deploy firestore.rules, confirm signed-in user, and ensure rules have propagated. Build issues: run npm install, npm run typecheck, and inspect Next.js errors.

Third-party components

Next.js, React, Firebase SDK, Lucide, Recharts, Google Fonts. Review each dependency's current license and any redistribution conditions before commercialization. No CrypGo code or imagery is incorporated.
